# Lucky 7 font assets

These unmodified WOFF2 Latin subsets are the same font families, versions, styles,
and weights previously requested from Google Fonts by all four public pages.
Self-hosting removes the third-party stylesheet request while retaining
`font-display: swap` in `/fonts.css`. The original unicode ranges are retained.

Downloaded on 2026-10-12 from Google's public font service. The site uses English
copy; additional language coverage requires the corresponding licensed subsets.
